## PICK WEBAPP UI rule

For every UI implementation or refactor, read and follow:

`docs/PICK-UI-SYSTEM-V1.md`

PICK UI System v1 is mandatory for both ADMIN and MEMBER, on Desktop and Mobile.

Important:
- Reuse the shared action/card system.
- Keep card heights, spacing, icons and semantic colors consistent.
- Desktop layouts optimize horizontal comparison.
- Mobile layouts must reorder fields by business logic rather than mechanically collapsing desktop grids.
- Test ADMIN + MEMBER on desktop + mobile before committing.
- Preserve UTF-8 Vietnamese text.
